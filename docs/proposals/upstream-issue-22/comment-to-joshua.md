**What it adds.** Two values of `analysis.differential.method`:
`multinomial` and `dirichlet_multinomial`. Each fits one `MGLM::MGLMreg.fit`
model of the whole composition, conditioned on each sample's read total. Each
estimate is the change in a taxon's log ratio to a reference taxon
(`mn_reference_taxon`, or the most abundant fitted taxon).

**Why you may want it.**

- **It fills a gap the README names.** Today a user can choose a per-taxon NB
  model, which needs a size factor, or CLR plus Welch, which needs zero
  replacement. These two models need neither. A zero count is part of the
  likelihood, and a ratio between two taxa does not change with library size.
- **The Dirichlet-multinomial measures overdispersion.** It reports each
  group's concentration and theta, so a user can see when the multinomial's
  standard errors are too small.
- **It follows your rules.** Statistics go through R via RCall. MGLM is
  pinned in `renv.lock`, and a missing MGLM gives a named error and a 503.
  Nothing falls back to another method: separation, non-convergence, MGLM's
  own refusals and too many taxa are each reported with the reason. Tests
  compare with known references.
- **It is small.** One new R dependency: MGLM 0.2.3 from CRAN, pure R, with
  base-R imports only, GPL (>= 2) like zCompositions. The lockfile diff is 34
  lines. The change is one commit across 16 files.

**How it is tested.** The multinomial matches its closed form (pooled log
ratios; the variance is the sum of reciprocal pooled counts) to 1e-8. The
Dirichlet-multinomial matches `stats::optim` on an independently written
likelihood to 2e-3, with standard errors from `stats::optimHess`. With Julia
1.12.5, R 4.5.0 and the library restored from the branch's `renv.lock`, the
differential suite passes 511 of 511. The full unit and server suite fails
only on the live-tool probes for tools that machine did not have (cutadapt,
fastqc, multiqc, vsearch, swarm, cd-hit). Your CI has not run it yet; it will
on the pull request.

**Two limits, stated in the code and docs.** When a group shows no
overdispersion, its Dirichlet concentration has no finite estimate. The rows
are then marked `boundary` and keep their statistics, or MGLM's own refusal
is kept and names the flat group. Only when both groups are flat are the
estimates the multinomial's; the tests check both cases. MGLM's penalised
regression is not offered, because it has no valid Wald standard errors.
