## Native ALDEx2 and ANCOM-BC differential abundance

### What this does

Adds two values of `analysis.differential.method`, `aldex2` and `ancombc`, fitted in Julia by the registered package `CompositionalDA` (v0.1.0) on the raw count matrix, with no R session involved.

- `aldex2`: Dirichlet posterior Monte Carlo instances (prior 0.5), CLR differences, Welch and Wilcoxon tests, with the package's expected within-instance BH values kept as they are. The effect is a log2 CLR difference, not a fold change.
- `ancombc`: the original two-group sampling-bias model. The effect is a bias-corrected log2 fold change. Structural zeros are reported as a decision with a note saying whether the absence is in one group or both, and never receive a p-value.
- `DifferentialConfig` gains `mc_samples` (2 to 4096, default 128) and `seed` (0 to `typemax(Int32)`, default 1), checked in the constructor and at the config route.
- The route accepts a per-request `method` override, spelled and case-folded like the config key.
- Counts that do not fit `Int` are refused, a sample with no reads is left out and named, and fewer than two retained taxa are refused.
- A refusal by the package (`CompositionError`) is returned as `NoTaxonFitted` and reported as 422. Any other error from the package is not turned into a refusal.
- The panel, the CSV settings line, the config editor and the guide describe both methods.

`CompositionalDA` is declared in `[deps]` and `[compat]` (`"0.1"`) and resolved in `Manifest.toml` from the General registry. There is no optional loading and no stand-in backend: `differential.jl` imports the package.

### Where this departs from CONTRIBUTING

CONTRIBUTING says statistics run in R through RCall. These two methods run in native Julia instead, so this change conflicts with that line. The R packages ALDEx2 and ANCOMBC are used only to produce reference values for the tests (below), and they are not added to `renv.lock`.

### Reference values

`test/fixtures/native_da/` holds a 16-sample, 12-taxon count table and the output of the R packages on it, generated by `generate_reference.R` in the same folder (R 4.5.0, Bioconductor 3.22, ALDEx2 1.42.0, ANCOMBC 2.12.0). `test/unit/test_differential_native.jl` compares the package's rows, as produced through `differential_abundance`, with these values. R is not needed to run the tests.

Tolerances and their reasons:

- **ALDEx2.** The method is Monte Carlo, so two correct runs differ even with a fixed seed. The fixture has the mean of 25 R runs (128 instances, seeds 1001 to 1025) and the range of those runs for each value. A native value must lie within one range of the R mean. The range of 25 draws is about four standard deviations. The largest deviation seen is 0.59 of a range. P-values are compared as log10, floored at 1e-10.
- **ALDEx2 Wilcoxon, one taxon.** `taxon11` is absent from every sample of one group. ALDEx2 reports an expected Wilcoxon p below 1e-10 for it. The package reports 1.55e-4, the smallest p that ranks of 8 against 8 can give. This taxon's Wilcoxon values are not compared, and the Welch values are. This is a real difference between the two implementations and is left visible here.
- **ANCOM-BC.** The package and the R function do not share code or a stopping rule (tolerance 1e-7 and 1e-5), and the standard errors add the bias variance slightly differently. Largest observed differences: effect 0.011, standard error 0.0096. Tolerance is 0.02 on both. The Wald statistic must be within 10 percent of the R value plus 0.15 (largest observed: 7 percent of a large value, 0.12 of a small one). The decision at BH 0.05 must be the same. P-values are not compared directly, because the normal tail turns a small statistic difference into up to two orders of magnitude where p is below 1e-15.
- **ANCOM-BC structural zero.** Both implementations find `taxon11` structurally absent from group A. R prints an effect of 3.94 and a p of exactly 0 for it. The native method reports the decision and no number.

### How to run

```
julia --project=. -t 2 test/runtests.jl differential_native differential
bun test src/components/differentialTable.test.ts src/components/differentialCsv.fuzz.test.ts
```

To regenerate the fixtures (needs R with ALDEx2, ANCOMBC and their dependencies): `Rscript test/fixtures/native_da/generate_reference.R`.

### What this leaves out

- ALDEx2's other tests (`kw`, `glm`) and more than two groups. Both methods are two-group.
- ANCOM-BC2 and the multi-group ANCOM-BC options.
- The calibration of either method beyond agreement with R on this table.
- R packages in `renv.lock`: none added.

### Lockfile

`Manifest.toml` changes only to add `CompositionalDA` and the packages it needs. It is needed because the package is a new dependency.

### Tested with

Julia 1.12.5, R 4.5.0, bun 1.4.4.
